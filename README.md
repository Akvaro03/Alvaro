## Sobre mí

Soy Full Stack Engineer radicado en Rosario, Argentina, con más de 4 años de experiencia construyendo y evolucionando productos B2B.

Trabajo principalmente con **Node.js, TypeScript, React y Next.js**, participando desde el análisis técnico y el diseño de la solución hasta su implementación y entrega en producción. También tengo experiencia diseñando APIs REST, modelando bases de datos relacionales, optimizando consultas SQL e integrando servicios modernos con sistemas legados en .NET.

- Reduje aproximadamente un **50 % los tiempos de procesamiento** mediante optimización de bases de datos, índices y consultas SQL.
- Contribuí a reducir cerca de un **70 % los errores en producción** incorporando pruebas de integración en servicios y endpoints críticos.
- Participo en estimaciones, code reviews, definición técnica y trabajo directo con stakeholders.
- Me interesa construir productos mantenibles que resuelvan problemas reales, no solamente completar funcionalidades.

La estoy construyendo como un producto full stack con **Next.js, TypeScript, PostgreSQL, Prisma, React Query y Recharts**, priorizando una arquitectura mantenible, seguridad de los datos y una experiencia clara para el usuario.
